SOBRE EL PROYECTO

Metodología

Conoce cómo CañaData-IA transforma los datos públicos en información útil.

01

Datos abiertos

Archivos CSV históricos de las zafras publicados en el portal de datos abiertos del Gobierno de México.

02

Procesamiento

La interfaz filtra y resume los registros para presentar indicadores comparables y fáciles de interpretar.

03

Inteligencia artificial

El contexto relevante se envía a Llama 3B mediante la API local de Ollama para generar respuestas claras.
